### 📋 Список изменений (Changelog)

#### 👑 Главное
* **Подбор стратегий:** Ускорили подбор стратегий за счёт параллельных тестирований.
* **Профили модификаций:** Некоторые модификации могут создавать под себя профили и внутри них запускать подбор стратегий из внешних `.bat`-файлов.
* **Мод Hub:** Полностью выпилили встроенный мод Hub, который вызывал баги в работе программы. Обход блокировки Fortnite вынесен в [отдельный мод](https://github.com/peshk0v/Zapret-Mods/blob/main/Fortnite/README.md).
* **Backups:** Ограничили размер бэкапов программы.

#### 🎨 Улучшения интерфейса
* **Dashboard:** Добавлена анимация при подборе стратегий для модификаций.
* **Первоначальная настройка:** Кнопка «Продолжить» сдвинута, чтобы не загораживать кнопку «Развернуть» у карточек категорий.

#### 🐛 Исправления ошибок
* **Модификации:** Исправлены баги при добавлении модификаций.
* **Статус «Частично»:** Исправлен баг при автозапуске, связанный с настройками DNS.
* **Конфиг DNS Manager:** Визуальный баг с заторможенным появлением настроек у DNS Manager.
* **Менеджер профилей:** Визуальный баг с карточками в менеджере профилей, которые не менялись при смене темы.
* **Смена темы:** Баг с переключением темы (не всегда переключалась).
